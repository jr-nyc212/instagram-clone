# Design references

Put screenshots of the Scrimba design here before you start the CSS.

Suggested files:

- `full-page.png` — the whole mini-browser view.
- `post-closeup.png` — one post, zoomed, so you can estimate avatar size, icon size,
  and spacing.

On a Mac: Shift + Cmd + 4, drag over the scrim's mini-browser, then drag the file into
this folder from the Desktop.
